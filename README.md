# Integrating Near-Infrared Reflectance Spectroscopy and Genomic Data Using Kernel Methods

This repository contains the analytical pipeline for integrating genomic, phenomic, environmental, and weather-derived information using kernel methods to improve prediction of grain yield and 500-kernel weight (KW) in multi-environment maize trials.

## Pipeline overview

The official analytical workflow is organized in the following sequence:

1. `climate_data`
2. `matrizes`
3. `variance_components`
4. `analysis_prediction`
5. `analysis_prediction_run_outputs`
6. `visualization`
7. `script_tabelas_resultados_pipeline_v2.R`

## Bilingual structure

The pipeline follows the rule:

- **EN** = main mechanical version
- **PT** = functional version dependent on EN

In practice, the English files define the main execution logic, while the Portuguese files preserve the didactic structure and reuse artifacts already generated by the English workflow whenever necessary.

## Prediction stage

The prediction stage is currently divided into two parts:

- **Part I — `analysis_prediction`**: setup, model catalog, ETA specification, and cross-validation design
- **Part II — `analysis_prediction_run_outputs`**: run outputs, output inventory, and prediction metadata
