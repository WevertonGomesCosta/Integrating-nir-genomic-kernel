1. Introduction

This tutorial documents how the project constructs the core kernels used in the genomic prediction analyses. The goal is not simply to read files and calculate matrices. The goal is to transform heterogeneous information sources into aligned scientific objects that can be used in multi-environment prediction models.

The script integrates four data layers:

  1. Phenotypic records (Pheno): grain yield (GY) and kernel weight (KW) by genotype and environment.
  2. Genomic markers (Geno): SNP markers processed in numerical format.
  3. NIR spectra (NIR): phenomic measurements used to build a spectral similarity kernel.
  4. Environmental covariates (W): weather-derived descriptors generated in the climate tutorial.

The final outputs of this script are the matrices used later in the prediction models:

  • Linear kernels: ZG, ZP, ZEZE, ZW
  • Interaction kernels: ZGZE, ZPZE, ZGZW, ZPZW
  • Nonlinear Gaussian kernels: GGK, PGK, GGKE, PGKE, GGKW, PGKW
  • Nonlinear arc-cosine kernels: GAK, PAK, GAKE, PAKE, GAKW, PAKW

A key practical objective of this tutorial is to guarantee that all matrices are constructed in the same observation order. If the kernels are not perfectly aligned, the downstream prediction analyses become invalid.

matrix_to_long <- function(K, n_show = 60) {
  n_show <- min(n_show, nrow(K))
  K_sub <- K[seq_len(n_show), seq_len(n_show), drop = FALSE]
  df <- as.data.frame(as.table(K_sub))
  colnames(df) <- c("Row", "Column", "Value")
  df$Row <- factor(df$Row, levels = rev(rownames(K_sub)))
  df$Column <- factor(df$Column, levels = colnames(K_sub))
  df
}

check_kernel_alignment <- function(K, reference_ids) {
  tibble(
    n_rows = nrow(K),
    n_cols = ncol(K),
    is_square = nrow(K) == ncol(K),
    symmetric_names = identical(rownames(K), colnames(K)),
    aligned_with_reference = identical(rownames(K), reference_ids)
  )
}

6. Build the linear genomic kernel (K_G stored as ZG)

The genomic kernel measures similarity among observations based on SNP markers.

The legacy pipeline used in this project standardizes marker values within each environment-specific observation block before stacking the data. Although this is not the only possible strategy, we preserve it here to maintain compatibility with the downstream analyses already developed for the article.

The practical steps are:

  1. Sort the genotype matrix and remove the ID column.
  2. Subset the genotype matrix according to the genotypes observed in each environment.
  3. Standardize markers within each block.
  4. Stack the environment-specific matrices in the same order used by the observation table.
  5. Compute the linear kernel by the cross-product of the standardized marker matrix.
Geno <- Geno[order(Geno$taxa), ]

build_weather_block <- function(obs_ids, daily_sig, annual_sig, other_daily_sig = NULL) {
  main_daily <- as.data.frame(daily_sig[rep(1, length(obs_ids)), , drop = FALSE])
  rownames(main_daily) <- obs_ids

  if (is.null(other_daily_sig)) {
    other_daily <- NULL
  } else {
    other_daily <- as.data.frame(
      matrix(
        NA_real_,
        nrow = length(obs_ids),
        ncol = ncol(other_daily_sig),
        dimnames = list(obs_ids, colnames(other_daily_sig))
      )
    )
  }

  annual_block <- as.data.frame(annual_sig[rep(1, length(obs_ids)), , drop = FALSE])
  rownames(annual_block) <- obs_ids

  if (is.null(other_daily)) {
    out <- cbind(main_daily, annual_block)
  } else {
    out <- cbind(main_daily, other_daily, annual_block)
  }

  out <- as.data.frame(out)
  rownames(out) <- obs_ids
  out
}

12.1 Optimization function for the Gaussian kernel

The function below optimizes the Gaussian bandwidth parameter by maximizing the marginal likelihood.

margh.fun <- function(theta, y, D, q, nu = 0.0001, Sc = 0.0001,
                      nuh = NULL, Sch = NULL, prior = NULL) {
  h <- theta[1]
  phi <- theta[2]

  Kh <- exp(-h * D / q)
  eigenKh <- eigen(Kh)

  nr <- length(which(eigenKh$values > 1e-10))
  Uh <- eigenKh$vectors[, 1:nr, drop = FALSE]
  Sh <- eigenKh$values[1:nr]

  d <- t(Uh) %*% scale(y, scale = FALSE)

  lden <- -0.5 * sum(log(1 + phi * Sh)) -
    (nu + nr - 1) / 2 * log(Sc + sum(d^2 / (1 + phi * Sh)))

  if (!is.null(prior)) {
    lprior <- dgamma(h, nuh, Sch, log = TRUE)
  } else {
    lprior <- 0
  }

  return(-(lden + lprior))
}

13. Build nonlinear arc-cosine kernels

Arc-cosine kernels offer a second nonlinear representation. They are inspired by neural-network geometry and can capture hierarchical nonlinear patterns through recursive transformations.

13.1 Helper functions for arc-cosine kernels

AK1.fun <- function(X) {
  cosalfa <- cor(t(X))
  cosalfa[cosalfa > 1] <- 1
  cosalfa[cosalfa < -1] <- -1
  angulo <- acos(cosalfa)
  mag <- sqrt(apply(X, 1, function(x) crossprod(x)))
  sxy <- tcrossprod(mag)
  AK1 <- (1 / pi) * sxy * (sin(angulo) + (pi - angulo) * cosalfa)
  AK1 <- AK1 / median(AK1, na.rm = TRUE)
  colnames(AK1) <- rownames(X)
  rownames(AK1) <- rownames(X)
  return(AK1)
}

marg.AK <- function(y, AK1, ml) {
  lden.fun <- function(phi, nr, Uh, Sh, d) {
    lden <- -0.5 * sum(log(1 + phi * Sh)) -
      (nr - 1) / 2 * log(sum(d^2 / (1 + phi * Sh)))
    return(-lden)
  }

  vero <- function(y, GC) {
    Kh <- GC
    eigenKh <- eigen(Kh)
    nr <- length(which(eigenKh$values > 1e-10))
    Uh <- eigenKh$vectors[, 1:nr, drop = FALSE]
    Sh <- eigenKh$values[1:nr]
    d <- t(Uh) %*% scale(y, scale = FALSE)
    sol <- optimize(lden.fun, nr = nr, Uh = Uh, Sh = Sh, d = d,
                    lower = 0.0005, upper = 200)
    phi <- sol[[1]]
    log.vero <- 0.5 * sum(log(1 + phi * Sh)) -
      (nr - 1) / 2 * log(sum(d^2 / (1 + phi * Sh)))
    return(log.vero)
  }

  GC <- AK1
  l <- 1
  GC2 <- GC
  vero1 <- vero(y = y, GC = GC2)
  m <- 0

  while (m == 0 && (l < ml)) {
    l <- l + 1
    GC <- AK.fun(AK1 = GC2, nl = 1)
    GC2 <- GC
    vero2 <- vero(y = y, GC = GC2)
    if (vero2 < vero1) m <- 1
    vero1 <- vero2
  }

  return(l - 1)
}

AK.fun <- function(AK1, nl) {
  n <- nrow(AK1)
  AK <- AK1
  for (l in 1:nl) {
    Aux <- tcrossprod(diag(AK))
    cosalfa <- AK * (Aux^(-1 / 2))
    cosa <- as.vector(cosalfa)
    cosa[cosa > 1] <- 1
    cosa[cosa < -1] <- -1
    angulo <- acos(cosa)
    angulo <- matrix(angulo, n, n)
    AK <- (1 / pi) * (Aux^(1 / 2)) * (sin(angulo) + (pi - angulo) * cos(angulo))
  }
  AK <- AK / median(AK, na.rm = TRUE)
  rownames(AK) <- rownames(AK1)
  colnames(AK) <- colnames(AK1)
  return(AK)
}

16. Final remarks

This tutorial converts raw genomic, phenomic, and climatic information into a reproducible collection of aligned kernels ready for downstream prediction models.

From a scientific workflow perspective, this script plays a structural role in the project:

  • it defines the observation order used by the modeling stage,
  • it makes the environmental representation explicit,
  • it stores the kernels as reusable computational artifacts,
  • and it documents how the linear and nonlinear relationships were encoded.

In the next stage of the project, these kernels become the inputs for the genomic prediction models compared in the article.
